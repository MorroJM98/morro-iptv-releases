## Install

<details>
<summary><b>📺 Fire TV</b></summary>

1. On the Fire TV, install the free **Downloader** app from the Amazon Appstore.
2. In Downloader, enter the Fire TV download link from the table above and install the app.
3. If the Fire TV asks, turn on **Settings → My Fire TV → Developer Options → Install Unknown Apps** for Downloader, and later for Morro IPTV too, so it can install its own updates.

</details>

<details>
<summary><b>💻 Mac</b></summary>

1. Open the downloaded `.dmg` and drag **Morro IPTV** onto **Applications**.
2. The first time, macOS may say it can't check the app. Open **System Settings → Privacy & Security** and choose **Open Anyway**.

New Mac versions appear on this page: download and drag the app in again to update.

</details>

<details>
<summary><b>🖥️ Windows</b></summary>

1. Run the downloaded `.msi`.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**.

</details>

## Features

- **Live TV** with what's on now and next, favorite channels in your own order, and a country filter
- **Movies and series** with details pages, Continue Watching, and a **NEW** label when a show you follow gets new episodes
- **A Home page** with everything you're watching in one place
- **Your choice of picture and subtitle size**, audio language and subtitles remembered per series
- Channels listed once, playing their best version, with automatic reconnecting if a stream drops

---

<sub>Morro IPTV doesn't include any channels or content: it plays what your own provider offers. The Mac and Windows apps use the VLC engine (LGPL 2.1).</sub>
